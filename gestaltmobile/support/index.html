Support

For TestFlight support, use TestFlight beta feedback from the build invitation or the TestFlight app. For App Store support, open a public issue in the GESTALT Mobile support tracker.

Include the app version, iOS version, paired Mac substrate version, and a brief description of the pairing, voice, canvas, review, or privacy workflow involved.

Do not include API keys, device tokens, customer code, private repository names, or raw transcripts in support reports.
