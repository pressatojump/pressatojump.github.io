GESTALT Mobile

Privacy Policy

GESTALT Mobile is a thin client for a paired Mac substrate. The iPhone app stores the Groq speech-to-text API key and Mac-issued device token in the iOS Keychain using kSecAttrAccessibleWhenUnlockedThisDeviceOnly.

Connected canvas snapshots are cached locally for offline restore as app functionality. Voice command history, canvas interaction statistics, and app usage statistics are opt-in categories. All three default to off. When a category is disabled, associated local data is purged within 60 seconds. Consented context is stored locally in Application Support/GESTALT/gestalt_context.db and is not sent to the substrate unless the user explicitly exports or shares it.

LLM provider keys are not stored on the iPhone. LLM requests are proxied through the paired Mac substrate over the authenticated local WebSocket connection.

The app does not include third-party analytics or advertising SDKs. Voice audio is sent to the configured Groq speech-to-text endpoint only when the user starts voice capture; if that request fails, the app can use Apple's on-device Speech recognizer as a local fallback when the selected language is supported.

For privacy or data deletion questions, use the support channel listed on the support page.
